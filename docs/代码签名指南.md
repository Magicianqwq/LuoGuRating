# 为什么会被 Windows 拦，以及怎么让它不被拦

## 先分清两种「拦」

| 拦截方式 | 长什么样 | 谁来管 |
| --- | --- | --- |
| **SmartScreen** | 蓝色窗口「Windows 已保护你的电脑」，底下「更多信息 → 仍要运行」 | 微软的声誉系统 |
| **杀毒软件** | Defender / 360 / 火绒 弹窗报毒或直接删文件 | 各家启发式引擎 |

实测：这份 exe 交给 Defender 扫描（先打上「来自网络」标记 ZoneId=3 再扫），**没有报毒**。所以绝大多数用户遇到的其实只是 SmartScreen。

## 普通人（你的用户）怎么办

1. 右键 exe → **属性** → 最下面勾「**解除锁定**」→ 确定。这一步去掉的是「文件来自网络」的标记（MOTW），很多时候勾完就不弹了。
2. 还是弹，就点「**更多信息**」→「**仍要运行**」。

命令行批量解除：

```powershell
Get-ChildItem -Recurse -File | Unblock-File
```

仓库里带了 `tools/unblock.ps1`，效果一样。

## 你能不能从程序里「绕过去」

**不能。** SmartScreen 判断的是三件事，都跟程序内部写了什么无关：

1. 有没有受信任 CA 签发的代码签名证书；
2. 证书对应的发布者累积了多少下载量声誉；
3. 文件有没有 MOTW 标记。

所以任何「改注册表」「加白名单」「混淆代码」的偏方，都只能骗自己，骗不了别人的电脑——而且改注册表本身就更容易被杀软盯上。

## 唯一靠谱的路：代码签名

### 选哪个服务

| 方案 | 价格 | 门槛 | 适合 |
| --- | --- | --- | --- |
| **SignPath Foundation** | 免费 | 项目必须开源、有公开仓库、经过一次人工审核 | 开源项目首选 |
| Azure Trusted Signing | 约 9.99 美元/月 | 个人开发者需要 **Entra ID P2 / Governance 订阅**（这是个大坑，实际成本远超标价） | 商业项目 |
| 传统 OV/EV 代码签名证书 | 200–500 美元/年 | 需要企业资质、还要硬件 token | 企业 |

自签名证书**没用**：SmartScreen 只认受信任 CA 签的证书，自签的反而会多一条警告。

### SignPath Foundation 申请资格逐条对照

申请前拿这张表自查，任何一条不满足都会被拒：

| 要求 | 说明 | 你的情况 |
| --- | --- | --- |
| No malware | 不能有恶意行为 | 纯查询工具，不改系统 |
| OSS License | 必须有明确的开源许可证，且**没有商业双授权** | MIT / 见 LICENSE |
| No proprietary code | 不能包含闭源组件 | 单文件源码全公开 |
| Maintained | 项目要有人维护，不是废弃状态 | 持续维护 |
| Released | 必须**先发过一个 Release** | **先去 GitHub 发一版** |
| Documented | 要有 README 等文档 | 已有 |
| 首页有 code signing policy | README 里必须有 `### Code signing policy` 小节，写明 Committer / Reviewer / Approver | 已加 |
| 只签自己的代码 | 不能给第三方二进制签名 | 符合 |
| 隐私 | 不能收集用户数据 | 数据全在本地 `data\` |
| 不改系统配置 | 不能写注册表、装服务、开机自启 | 解压即用 |
| 要求开启 MFA | 仓库维护者必须开两步验证 | **去 GitHub 设置里开** |

### 申请步骤

1. **先把仓库公开**，并在 GitHub → Settings → Password and authentication 里**开启 2FA**。
2. **打一个 Release**：`git tag v1.0.0 && git push origin v1.0.0`，然后在 GitHub 上基于这个 tag 发布 Release，把 `LuoguScorer.exe` 传上去。
3. 确认 README 里的 **`### Code signing policy`** 小节还在（SignPath 会人工检查这一节）。
4. 打开 <https://signpath.org/>，点 **Apply for free signing**，填仓库地址、说明项目用途。
5. 审核通过后，SignPath 会给你一个 organization id 和 API token，把它们填到 GitHub 仓库的 **Settings → Secrets and variables → Actions**：
   - `SIGNPATH_API_TOKEN`
   - `SIGNPATH_ORGANIZATION_ID`
6. 之后每次发 Release，`.github/workflows/sign-release.yml` 会自动把 exe 送去签名。

### 签完就没弹窗了吗

不是立刻。签名之后还要**积累下载量声誉**，一般要几百到几千次下载，SmartScreen 才会彻底安静。但至少从「未知发布者」变成了「已验证的发布者」，信任度完全不同。

## 签名前还能做的

这些已经做了，能让程序「看起来不像可疑文件」：

- 嵌入图标和 `VERSIONINFO`（属性页里能看到「洛谷计分器 1.0.0.0」）；
- 嵌入 manifest：`asInvoker`（不要管理员权限，不触发 UAC）、Per-Monitor V2 DPI、声明支持 Win10/11；
- 链接时开 `--nxcompat`、`--dynamicbase`、`--high-entropy-va`（ASLR / DEP），并 `strip` 掉符号；
- 不加壳、不自解压、不带下载器行为。

## 如果你只是自己用

自己电脑上编出来的 exe 不带「来自网络」标记，本来就不弹。想让别人也不弹，只能签名。
